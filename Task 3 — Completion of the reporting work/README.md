# Задание 3 — Оформление отчётной работы

Оформите работу в LaTeX на произвольную тему. Требования к содержимому работы:

1. В работе должно присутствовать не менее 3-х разных математических формул

2. В работе должно присутствовать не менее 2-х изображений

3. В работе должно присутствовать не менее 1-ой таблицы

4. Должен присутствовать программный код, оформленный с помощью minted 

5. Должен присутствовать список источников, используемых в рамках работы

6. Используйте шаблон СГУ для курсовых работ на LaTeX 

На что стоит обратить внимание:

1. При оформлении специальных символов следует использовать специальные последовательности символов

2. Код должен быть отформатирован с помощью настроек, которые были разобраны на паре и приведены в лекции на курсе.

3. Все упоминания переменных должны сопровождаться специальным моноширинным шрифтом (вспоминаем про \texttt, \verb и \mintinline).

4. В нужных местах необходимо проставить ссылки на источники. Обратите внимание, что нумерация источников может отличаться, потому что в данном случае вы работаете лишь с фрагментом курсовой. Однако, номер источника должен быть проставлен автоматически, а сама ссылка — кликабельной (вспоминаем про \cite).

5. Аналогичные п.3 замечания относительно ссылок на изображения и приложения

Для более быстрой и эффективной работы предлагаем придерживаться следующих советов:

1. Стоит установить стандартные настройки форматирования minted для языка С++ и Python с помощью команды \setminted.

2. По возможности стоит использовать команду вставки кода из файла \inputminted. В случае невозможности применения этой команды (например, когда одновременно упомянается лишь фрагмент кода), стоит скопировать нужный фрагмент и вставить в окружение minted.

3. Ссылки на изображения и приложения следует оформлять в формате \label{reftype:refname}, где reftype — тип ссылки. Например, формула — eq, изображение — fig, код — code, приложение — app (приведены примеры названий, ваши могут отличаться)

4. Не стоит допускать файлов размера более 500 строк, по возможности разбивайте проект на несколько файлов и подключайте их с помощью \input или \include
